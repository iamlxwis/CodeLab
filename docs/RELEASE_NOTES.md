# Reimagined 2.1 — 0.6.1-alpha

Merged into main on November 25, 2026. Public release publication is separate.

## What's new

- Compact editor, responsive tabs, keyboard-aware coding keys and simplified workspace modes.
- Offline/Online selection at Run and Rerun, with revision-bound online upload consent.
- Code, Result and Combined snippet exports with Light and Dark themes, full-file capture and pagination.
- Distinct Home and Projects, responsive language-branded cards, grouped settings, Explore and universal search.
- Backdrop-aware navigation and clearer runtime status.

## Verification

The branch candidate passed 202 JVM tests, 50 Android instrumentation tests, strict lint and all ten Android 15 smoke stages. A signed in-place upgrade preserved project data and appearance. Physical GPU performance, TalkBack, live online execution and secondary flows remain outstanding; emulator motion performance remains a concern.
